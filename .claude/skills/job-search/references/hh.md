# hh — нажатие «Откликнуться» делает оркестратор

Агенты до кнопки доходят, нажимает оркестратор сам, в Chrome с живой сессией пользователя.

## Порядок
1. Из лога агента возьми партию откликов (ссылки + ответы на скрининговые вопросы).
2. Открой вакансию, нажми «Откликнуться». В окне выбери **нужное резюме** (если их несколько).
   Сопроводительное — пустое, если форма не требует обратного (тогда `templates/hh-cover.md`).
3. Ответы на скрининговые вопросы — правдиво, из `data/candidate.md`.
4. **Успех проверяется только по `hh.ru/applicant/negotiations`** — вакансия должна появиться в
   списке откликов. Клик без эффекта и чужая кнопка (панель расширения, рекомендации) случаются.
5. Только после этого — `ledger.py mark-sent <компания> --channel hh`.

## Ограничения
- Не больше ~6–7 откликов в день: платформа замечает массовость.
- «Отклик не создаётся» (вакансия в архиве, требуется тест, работодатель закрыл приём) — не повторять
  вслепую, взять другую цель.
- Тест-экзамен — не проходить (см. `core/sending.md`): ссылка пользователю, цель заменить.
- Данные для сторожа входящих: `bin/browser/hh_chats_awaiting.js` (выполнять на hh.ru/chat),
  поля вакансий: `bin/browser/hh_vacancy_fields.js`.
