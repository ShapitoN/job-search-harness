# STATE — где остановились

Оркестратор читает этот файл первым в каждом прогоне. Держать до ~15–20 КБ: всё, что старше
трёх суток и уже не нужно для решений, уносить в `STATE-archive.md`.

## Последний прогон
- Дата:
- Разведка (доски / Telegram) последний раз: 
- Действий за день: 0 из <квота>

## Пул на следующий прогон
Цели, найденные разведкой и ещё не использованные. Формат: компания · вакансия/канал · ссылка · канал связи.

## Ждёт вашего действия
Только то, что требует вашего хода (см. список в SKILL.md, «Что решаете вы»). Нечего — «ничего».
