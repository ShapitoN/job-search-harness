# Job Search Harness

Система поиска работы на **Claude Code**: один оркестратор и семь агентов-воркеров, которые
каждый день ищут вакансии, готовят резюме под них, пишут и отправляют письма и отклики
в пределах суточной квоты, отвечают работодателям и сообщают вам только то, где нужен именно
ваш ход. Всё остальное делают скрипты, а не модель, — поэтому это не разоряет по токенам.

Собрана на реальном поиске работы (сотни писем, hh, Telegram) и обезличена: профиль, резюме,
журналы и ключи здесь не хранятся, они лежат в папке `data/` на вашей машине и в git не попадают.

## Как это работает

```
Вы: «Ищи работу»
  └─ Оркестратор (скилл job-search)
       ├─ inbox-watcher   чаты hh, где ждут ВАС → карточка в Telegram
       ├─ replier         отвечает работодателям (hh / почта / Telegram), 5 исключений — вам
       ├─ ledger-keeper   журнал: кому писали, окно дубля 30 дней, STATE.md
       ├─ разведка, не чаще раза в 2 суток, парой:
       │    scout-boards    hh и доски (скрипт scan_boards.py)
       │    scout-telegram  публичные каналы (скрипт scan_telegram.py)
       ├─ resume-tailor   резюме под вакансию → PDF, без единого выдуманного факта
       ├─ outreach        письма (отправка скриптом), отклики и Telegram — готовит
       ├─ оркестратор жмёт «Откликнуться» и «Отправить» сам и проверяет результат
       └─ один короткий отчёт в Telegram
```

Ключевые идеи:
- **Тот, кто ищет, не отправляет; тот, кто отправляет, не ведёт учёт.** Разделение полномочий
  работает лучше любых инструкций.
- **Проверки встроены в скрипты**, а не в промпты: письмо без вложения, с недописанной заглушкой,
  на мёртвый домен или повторно в ту же компанию просто не уйдёт.
- **Агент по умолчанию решает сам** и беспокоит вас только в пяти случаях: оффер, время созвона,
  тест-экзамен, личные данные, анкета на сайте работодателя.
- **Ничего не выдумывать.** Автономия — право действовать, а не сочинять опыт.
- **Экономия контекста**: тяжёлую механику (обход выдач, журнал, кодирование вложений) делают
  скрипты; воркеры пишут результат на диск по ходу; не больше двух агентов одновременно.

## Что понадобится
- [Claude Code](https://claude.com/claude-code) (подписка или API)
- Python 3.9+; для почты — `pip install google-api-python-client google-auth-oauthlib`, для PDF —
  `pip install markdown` и установленный Chrome/Chromium
- Расширение **Claude in Chrome** — для hh и Telegram Web (зайдите в них своим аккаунтом)
- Аккаунт Gmail для отправки писем (OAuth, инструкция в `docs/SETUP.md`)
- Бот в Telegram для уведомлений (по желанию, 5 минут через @BotFather)

## Быстрый старт
```bash
git clone <этот репозиторий> job-search && cd job-search
python3 bin/init.py          # создаст data/, config/search.json, шаблоны профиля и резюме
claude                       # откройте Claude Code в этой папке
```
Дальше скажите Claude: **«Помоги заполнить профиль»** — он проведёт интервью по `data/candidate.md`
и `data/resume/base.md`. Потом пройдите `docs/SETUP.md` (Gmail, Telegram, поиск) и запускайте
фразой **«Ищи работу»**.

## Что где лежит
| Путь | Что |
|---|---|
| `.claude/skills/job-search/` | оркестратор (`SKILL.md`) и справочники по hh, Telegram, инструментам |
| `.claude/agents/` | семь воркеров |
| `core/` | правила: отправка, экономия токенов, отказоустойчивость, шаблон профиля |
| `templates/` | письма, сообщение в Telegram, сопроводительное, резюме, `STATE.md` |
| `bin/` | скрипты: `send_email.py`, `ledger.py`, `scan_boards.py`, `scan_telegram.py`, `resume_pdf.py`, `notify.py`, `init.py`, `browser/*.js` |
| `config/search.example.json` | что искать: регион hh, роли, порог по деньгам, каналы, ключевые слова |
| `data/` (создаётся, не в git) | ваш профиль, резюме, журнал `ledger.csv`, логи прогонов |
| `STATE.md` (не в git) | где остановились; оркестратор читает его первым |

## Что настроить под себя
- Квота в сутки, как часто разведывать, размер партии — три числа в начале `SKILL.md`.
- Площадки и порог по деньгам — `config/search.json`.
- Тон и структура писем — `templates/`.
- Пять исключений «когда беспокоить вас» — `SKILL.md`, раздел «Что решаете вы».
- Автозапуск каждый день — планировщик Claude Code (скилл `schedule`); запускать только когда
  всё отлажено вручную хотя бы неделю.

## Ограничения и честность
- Массовая рассылка спамит работодателей и вас самих: держите квоту разумной (10–20 в день) и
  добавляйте абзац «под компанию» по каждому адресату — без него письмо не должно уходить.
- hh и Telegram меняют вёрстку; скрипты в `bin/browser/` и `scan_boards.py` иногда придётся чинить.
  Агенты устроены так, что сбой источника не останавливает цикл.
- Следите за условиями площадок: автоматизация откликов может нарушать правила сервиса.
- Система отвечает от вашего имени. Первую неделю запускайте с проверкой каждого письма
  (оставляйте черновики, смотрите `data/log/`), и только потом доверяйте полностью.
