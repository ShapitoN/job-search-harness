# Настройка

Займёт 30–40 минут один раз. Порядок: профиль → поиск → почта → Telegram → пробный прогон.

## 1. Профиль (самое важное)
```bash
python3 bin/init.py
```
Откройте Claude Code в папке и попросите: «Помоги заполнить профиль». Нужны два файла:
- `data/candidate.md` — контакты, что ищете, деньги, факты об опыте, формулировка причины ухода,
  чего не рассматриваете. **Это единственный источник фактов для всех агентов.**
- `data/resume/base.md` — базовое резюме. Агент `resume-tailor` будет переставлять и сокращать его
  под вакансию, но никогда не добавит то, чего там нет.

Сформируйте PDF основного резюме: `python3 bin/resume_pdf.py data/resume/base.md` → PDF рядом.
Рекомендательное письмо или другие вложения кладите в `data/resume/` и указывайте в `--attach`.

Чёрный список (бывший работодатель, компании, которым писать нельзя) — `data/blacklist.txt`,
и продублируйте их в журнале: `python3 bin/ledger.py add "Компания"` + `set-status … blocked`.

## 2. Что искать — `config/search.json`
- `boards.main.host` — `hh.ru` (или hh.kz, hh.by); `area` — код региона hh (113 Россия, 40 Казахстан,
  1 Москва, 2 Санкт-Петербург); `roles` — коды профессиональных ролей (справочник
  `https://api.hh.ru/professional_roles`); `min_salary` и `currency` — порог.
- `telegram_channels.main` — публичные каналы с вакансиями (имена без `@`). Начните с 3–5 живых,
  проверьте `python3 bin/scan_telegram.py --region main --dry-run`.
- `role_keywords` / `stop_keywords` — регулярные выражения: что считать подходящим постом, что мусором.

Проверка: `python3 bin/scan_boards.py --region main` должен напечатать таблицу вакансий.

Несколько регионов или стран — добавьте ключи рядом с `main` и вызывайте с `--region <ключ>`.

## 3. Почта — Gmail API
Письма уходят через `bin/send_email.py` (вложения кодируются на диске, это дёшево по токенам).
1. [Google Cloud Console](https://console.cloud.google.com/) → новый проект → **APIs & Services → Library →
   Gmail API → Enable**.
2. **OAuth consent screen**: тип External, добавьте себя в Test users.
3. **Credentials → Create credentials → OAuth client ID → Desktop app**, скачайте JSON.
4. Положите его в `~/.config/job-search/credentials.json`.
5. `pip install google-api-python-client google-auth-oauthlib`
6. `python3 bin/send_email.py auth` — откроется браузер, разрешите доступ.
7. Проверка без отправки: `python3 bin/send_email.py send --to you@example.com --subject t --body-file <файл с текстом >200 символов> --attach data/resume/base.pdf --dry-run`

Приложение в режиме Testing теряет доступ **каждые 7 дней** — просто повторите `auth` (скрипт
напомнит в Telegram, если он настроен). Публиковать приложение для личного использования не нужно.

## 4. Telegram-уведомления (по желанию, но рекомендуется)
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Напишите своему боту любое сообщение, затем откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":…}` — это chat_id.
3. Создайте `~/.config/job-search/telegram.json`: `{"token": "…", "chat_id": "…"}`
   (или переменные `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`).
4. Проверка: `python3 bin/notify.py "привет"`.

Без бота всё работает, но сообщения «ждёт ответа» и отчёт будут только в терминале — а их легко
пропустить.

## 5. Браузерные каналы (hh, Telegram Web)
Установите расширение **Claude in Chrome**, войдите в hh.ru и в `web.telegram.org/k/` своими
аккаунтами в том же Chrome. Агенты работают в вашей живой сессии; пароли им не нужны и не должны
передаваться.

## 6. Пробный прогон
1. `python3 bin/ledger.py stats` — журнал создастся.
2. В Claude Code: **«Ищи работу»**. В первый раз попросите оркестратора: «Сегодня без отправки,
   только разведка и черновики» — проверьте найденное и тексты писем в `data/log/`.
3. Когда тексты вас устраивают, включайте отправку с маленькой квотой (3–5 в день), через неделю
   поднимайте до 10–15.
4. Автозапуск по расписанию — только после недели ручных прогонов.

## Если что-то не работает
| Симптом | Причина |
|---|---|
| `ОТКАЗ: нет token.json` | не пройден `auth` или прошло 7 дней — повторить `auth` |
| `scan_boards` пишет «не нашёл HH-Lux-InitialState» | hh изменил вёрстку или отдал капчу; зайдите в hh вручную, подождите |
| `scan_telegram` вернул 0 постов | канал приватный/закрыт для превью или опечатка в имени |
| Агент «умер» без отчёта | упёрся в лимит сессии; посмотрите его файл в `data/log/` — он писал по ходу |
| Письмо не отправляется «домен не принимает почту» | адрес мёртвый; найдите другой на сайте компании или откликнитесь на hh |
