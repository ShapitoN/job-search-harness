# Поиск работы — агентная система на Claude Code

Запуск: сказать в этой папке **«Ищи работу»** — сработает скилл `job-search` (оркестратор).
Устройство и правила: `README.md`, `.claude/skills/job-search/SKILL.md`. Первый запуск и настройка: `docs/SETUP.md`.

Принципы, обязательные для всех сессий здесь:
- Единственный источник фактов о кандидате — `data/candidate.md` и `data/resume/base.md`. Ничего не выдумывать.
- Отправка писем — только `bin/send_email.py`; журнал — только `bin/ledger.py`; вывод каждого вызова ограничивать (`core/token-rules.md`).
- Личные данные (`data/`, `STATE.md`, `config/search.json`, токены) в git не попадают — см. `.gitignore`.
- Если `data/candidate.md` ещё не заполнен — сначала помоги пользователю заполнить его (интервью по полям шаблона), а не запускай цикл.
